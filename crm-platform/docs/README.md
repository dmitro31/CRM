# CRM Platform

## About

CRM Platform — це SaaS-платформа, яка дозволяє компаніям створювати власу CRM без написання коду.

Кожна компанія отримує окремий Workspace, де може:

- створювати власні модулі;
- створювати власні поля;
- керувати користувачами;
- налаштовувати ролі;
- працювати із записами;
- автоматизувати бізнес-процеси;
- використовувати AI для виконання рутинних задач.

Проєкт створюється як демонстрація сучасної архітектури Backend та Frontend і є основним проєктом мого портфоліо.

---

# Main Features

- Multi-tenant Architecture
- Dynamic Modules

- Dynamic Forms
- Records Management

- File Storage
- Audit Log
